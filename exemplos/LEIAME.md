# Documentos de exemplo

Estes 12 documentos (8 PDF e 4 DOCX) existem só para demonstração: servem para experimentar o Lume
e aparecem nos prints do README e do manual.

Para usar, abra o Lume e arraste esta pasta inteira para a janela (ou use **Adicionar documentos →
Importar uma pasta inteira…**). O Lume copia os arquivos para a biblioteca dele; esta pasta continua igual.

Todo o conteúdo foi escrito para este projeto e é **fictício**: pessoas, empresas, cooperativas, livrarias,
cidades, valores e números não existem. Não há dados pessoais nem material protegido por direitos autorais.

O arquivo `manifest.json` descreve cada documento (título, autor, etiquetas, estante e coleção sugeridas)
e é usado pelos testes de interface para montar a biblioteca dos prints.
